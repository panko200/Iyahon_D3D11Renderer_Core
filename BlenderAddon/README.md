# YMM4 D3D11 Auto-Bake GLB Exporter (Blender アドオン) v1.2.0

Blender で作成した **複雑なシェーダーノード（ノイズ・プロシージャル質感・Mix Shader・ノードグループ・Bump 等）や UV 未展開のモデル** を、**元のオブジェクト・マテリアル・レンダー設定（EEVEE 等）を一切壊さずに** 自動複製・スマート UV 展開・Cycles ベイクして、ゆっくりムービーメーカー4（`Iyahon_D3D11Renderer_Core`）の「D3D11 3Dモデル」へそのまま読み込める `.glb` 形式で書き出す Blender アドオンです。

## 対応 Blender バージョン

- **Blender 3.x / 4.x / 5.x** 対応（Blender 3.2 / 4.1 / 5.1 で動作確認済み）

---

## インストール・アップデート方法

1. Blender を起動し、上部の **編集 (Edit)** → **プリファレンス (Preferences)** を開きます。
2. **アドオン (Add-ons)** タブを開きます。
   - **v1.0 など旧バージョンを入れている場合**: 一度既存の `YMM4 D3D11 Auto-Bake GLB Exporter` のチェックを外して **削除 (Remove)** し、Blender を再起動するか、新しい `ymm4_d3d11_glb_exporter.py` を入れ直してください（N パネルに **`v1.2.0`** と表示されていれば更新完了です）。
3. 画面右上（Blender 4.2 以降では右上の `v` メニュー）にある **ディスクからインストール (Install from Disk / Install...)** をクリックします。
4. `ymm4_d3d11_glb_exporter.py` を選択してインストールします。
5. 一覧に表示された **「Import-Export: YMM4 D3D11 Auto-Bake GLB Exporter」** にチェックを入れて有効化します。

### v1.2.0 での変更点
- **ガラス（屈折・IOR フレネル反射）対応**: `Principled BSDF`（Transmission / Transmission Weight）および単一 `Glass BSDF` / `Refraction BSDF` を半透明ブレンドではなく **`KHR_materials_transmission` + `KHR_materials_ior`** として正確に出力するようになりました（再ベイクした `.glb` を YMM4 で読み込むことで屈折・映り込みが有効になります）。

## 使い方

1. 3D ビューポートで書き出したいモデルを選択します（または「表示中の全メッシュ」を選択）。
2. 3D ビューポート右端のサイドバー（**`N` キー**）を開き、**「YMM4 D3D11」** タブを選択します。
   - （または上部の **ファイル (File)** → **エクスポート (Export)** → **YMM4 D3D11 自動ベイク (.glb)** からも開けます）
3. 用途に合わせて解像度やオプションを確認します（基本的には初期設定のままで OK です）。
   - **テクスチャ解像度**: 標準は `1024 x 1024`（メインのキャラや大きく映す背景などは `2048 x 2048` 推奨）
   - **UV展開モード**:
     - `常に新規ベイクUV生成（推奨）`: 元マテリアル内の既存 UV テクスチャも参照しつつ、重複のないベイク専用 UV を複製メッシュ側に新規生成します。UV 未展開モデルやプロシージャルノードが混在するモデルでもそのままベイクできます。
     - `UV未展開のみ自動展開`: すでに綺麗に UV 展開されているメッシュの UV をそのまま使いたい場合向け。
   - **計算デバイス**: 普段 EEVEE のまま作業していても、出力時だけ内部で Cycles を使ってベイクし、終了後すぐに元の設定へ戻します。
4. **「自動ベイクして GLB 出力」** ボタンを押し、保存先と `.glb` ファイル名を指定して書き出します。
5. YMM4 側の **「図形」 → 「D3D11 3Dモデル」** で書き出した `.glb` ファイルを指定します。

## 特徴と仕組み

- **非破壊処理**: 対象オブジェクトやマテリアル、モディファイア、レンダーエンジン設定、選択状態をすべて退避し、作業は一時コレクション内の複製に対してのみ行います。終了後に一時データを全削除して元の状態へ戻します。
- **Cycles での全 PBR マップ対応**:
  - `Base Color`（アルファ透過・マスク対応）
  - `Metallic` / `Roughness`（Emission 経由ベイク＋glTF 標準 ORM テクスチャ自動パッキング）
  - `Normal` / `Bump` / `Displacement`（タンジェント空間ノーマルマップ）
  - `Emission`（空間発光マップ＋`KHR_materials_emissive_strength` HDR 強度対応）
  - `Transmission` / `IOR`（ガラス等の透過屈折用 `KHR_materials_transmission` + `KHR_materials_ior` 出力対応）
- **最適化**: 単一色など変化のないチャンネルは無駄なテクスチャを生成せず数値パラメータとして書き出し、ファイル容量を抑えます。
- **Draco 圧縮なし**: `Iyahon_D3D11Renderer_Core` がそのまま高速読み込みできる非 Draco `.glb` を出力します。

## 注意点

- **`Shader to RGB` ノードについて**: `Shader to RGB` は Blender EEVEE 専用ノードであり、Cycles では評価されません（黒または未反映になります）。EEVEE のトゥーン調シェーダー等をベイクする場合は、`ColorRamp` や標準ノード構成へ置き換えてから書き出してください。
- **外部・プロシージャル背景のみ反映**: ワールド環境光やカメラ角度に依存する効果（ビュー空間フレネルやワールド反射など）は静的なマテリアルベイク対象外です。反射や環境映り込みは YMM4 側の **D3D11 ライティング / HDRI 環境マップ / SSR** によってリアルタイムに計算されます。
